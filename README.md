# とんマッチ（モック）

やりたいこと・割り振りたいタスクを文章で書くと、とんペディアのメンバーから
適性の高い人を **理由つきで5人** 提示する Web アプリのモックです。

東北大学 とんペディア／AI Builders Camp の題材として作成しています。
掲載されている96名はすべて **架空のモックデータ** で、実在の人物ではありません。

## 動かし方

ビルド不要・依存パッケージなしで動きます。Node.js 20 以上が必要です。

```bash
node tools/serve.mjs   # → http://localhost:5173
```

`index.html` を直接ブラウザで開いても動作します（`assets/data.js` を script タグで
読み込んでいるため、`file://` でも動くようにしてあります）。

## 構成

| パス | 役割 |
| --- | --- |
| `index.html` | 画面・スタイル・マッチングロジックすべて。1ファイル完結 |
| `assets/data.js` | 画面が読み込むモックデータ（**自動生成。直接編集しない**） |
| `mock_profiles.csv` | 同じデータのCSV版（BOM付きUTF-8・CRLF。**自動生成**） |
| `tools/gen-mock.mjs` | 上記2ファイルの生成スクリプト |
| `tools/serve.mjs` | 依存なしの静的サーバー |
| `tools/check.mjs` | 検証スクリプト（CIが実行） |

## 画面

1. トップ／検索 — やりたいことを自由文で入力
2. 検索結果 — 適性順に最大5名、それぞれ理由つき
3. メンバー詳細 — 興味・できること・稼働時間・経験・人柄
4. メンバー一覧 — 部門（開発部／広報部／営業部）で絞り込み
5. プロフィール登録 — その場で検索対象に加わる（モックのためリロードで消えます）

## モックデータを変更する

`assets/data.js` と `mock_profiles.csv` は生成物です。内容を変えるときは
`tools/gen-mock.mjs` を編集してから再生成してください。

```bash
node tools/gen-mock.mjs
```

CIが「生成スクリプトの出力」と「commit済みファイル」の一致を検証するため、
再生成した結果もあわせてcommitする必要があります。

## 検証

```bash
node tools/check.mjs
```

文字コード、`index.html` のインラインスクリプトの構文、`assets/data.js` が画面の
期待する形になっているか、検索ロジックが例外なく想定件数を返すかを確認します。
GitHub Actions では Node 20 / 22 / 24 で、これに加えて再生成の再現性と
静的サーバーの疎通も確認しています（[.github/workflows/ci.yml](.github/workflows/ci.yml)）。

## 本実装に向けて

`index.html` の `search()` / `reasonOf()` はキーワードスコアリングによるモックです。
本実装では **LLMへの1リクエスト** に差し替える想定で、返り値の形
（`id` / `rank` / `reason`）は変えずに済むようにしてあります。
